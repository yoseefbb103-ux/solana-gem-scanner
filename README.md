# ماسح إشارات سولانا

لوحة مراقبة **للقراءة فقط** تلتقط أحدث ملفات توكنات سولانا العامة ثم تربطها بأزواجها المتاحة لتعرض ترتيباً قابلاً للتفسير لدرجة الفرصة ودرجة المخاطرة. لا تربط هذه النسخة أي محفظة، ولا تنشئ أو ترسل أوامر شراء أو بيع، ولا تتعامل مع مفاتيح خاصة.

> **تحذير مالي:** المخرجات تحليل آلي لبيانات سوق عامة عالية التذبذب، وليست توصية شراء أو بيع أو احتفاظ، وليست وعداً بعائد أو حماية من الخسارة.

## ما الذي تنفذه النسخة الأولى؟

| المجال | التنفيذ |
| --- | --- |
| مصدر البيانات | يقرأ الخادم آخر ملفات التوكنات من واجهة DEX Screener العامة، ويقتصر على `solana`، ثم يطلب أزواج كل توكن ليختار الزوج الأعلى سيولة. لا يحتاج هذا المسار إلى مفتاح API. [1] |
| التحديث | زر فحص يدوي فقط. يعرض وقت آخر جلب وعدد المرشحين من المصدر، ولا توجد عملية خلفية أو مراقبة تلقائية. |
| التقييم | درجة فرصة من 100 ودرجة مخاطرة من 100، مع عوامل إيجابية وتحذيرات نصية يمكن مراجعتها داخل نافذة التفاصيل. |
| المرشحات | حد أدنى للسيولة، وحجم ساعة، وأقصى عمر للزوج، وأقصى درجة مخاطرة. تُحفظ الإعدادات واللقطات عند توافر `DATABASE_URL`. |
| التخزين | جداول منفصلة لعمليات الفحص واللقطات وإعدادات المرشحات؛ وتحسب اللقطة الجديدة فرق درجة الفرصة عن آخر لقطة للتوكن نفسه. |
| الأمان الوظيفي | لا توجد مكتبات محافظ، أو أزرار تداول، أو شبكات توقيع، أو واجهات إرسال معاملات. |

## منهجية التقييم

| البند | أثره على درجة الفرصة | أثره على المخاطرة |
| --- | --- | --- |
| السيولة بالدولار | حتى 25 نقطة؛ تكافئ السيولة الأعلى | السيولة الأقل من 25,000 دولار ترفع المخاطرة تدريجياً |
| حجم الساعة وعلاقته بالسيولة | حتى 22 نقطة؛ يكافئ النشاط القابل للمقارنة | نسبة حجم مفرطة إلى السيولة تُعلَّم كإشارة تحذير |
| عمر الزوج | حتى 15 نقطة ضمن نافذة حداثة متوازنة | الزوج الذي عمره أقل من ساعة يتلقى زيادة مخاطرة |
| عدد الصفقات وتوازنها | حتى 20 نقطة للنشاط وتوازن الشراء/البيع | اختلال قوي في الشراء والبيع يرفع المخاطرة |
| تغير السعر | حتى 18 نقطة لزخم إيجابي غير مفرط | تغير ساعة يتجاوز 35% أو تغير 5 دقائق يتجاوز 12% يُصنَّف حركة حادة |

هذا النموذج **قاعدة فرز شفافة وليست نموذج تنبؤ**. لا يمكنه اكتشاف الضرائب الخفية، أو صلاحيات العقد، أو تمركز الحيازات، أو كل أشكال الاحتيال؛ لذلك ينبغي اعتبار درجة الخطر الدنيا إشارة بيانات محدودة، لا شهادة سلامة.

## التشغيل المحلي

يتطلب المشروع Node.js 22.13.0 وقاعدة بيانات MySQL أو TiDB متوافقة. يستخدم المشروع `pnpm`.

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/solana-gem-scanner.git
cd solana-gem-scanner
corepack enable
pnpm install --frozen-lockfile
export DATABASE_URL='mysql://USER:PASSWORD@HOST:3306/solana_scanner'
export JWT_SECRET='replace-with-a-long-random-secret'
pnpm drizzle-kit migrate
pnpm dev
```

افتح `http://localhost:3000` ثم اضغط **تحديث يدوي**. إن لم تُعرّف `DATABASE_URL`، تعمل اللوحة لجلب النتائج الحية ولكنها لا تحفظ اللقطات أو الإعدادات.

## النشر على Render

يحتوي المستودع على `render.yaml` يعرّف خدمة Node Web Service. عند ربط المستودع، يقرأ Render ملف الإعداد من جذر المستودع، وينفذ أمر البناء والتشغيل المعرّفين فيه. يدعم Render حقول `buildCommand` و`startCommand` و`preDeployCommand` ومتغيرات البيئة داخل الـ Blueprint. [2]

| الإعداد في Render | القيمة |
| --- | --- |
| Blueprint | اختر **New → Blueprint** بعد ربط مستودع GitHub الذي يحتوي `render.yaml` |
| `DATABASE_URL` | أدخل رابط MySQL/TiDB متاحاً من خدمة خارجية؛ طبقة البيانات في هذا المشروع تستخدم `mysql2` وليست PostgreSQL |
| `JWT_SECRET` | يولَّد تلقائياً في ملف الإعداد؛ احتفظ بقيمة خاصة إذا عدّلت إعداد المصادقة لاحقاً |
| البناء | `corepack enable && pnpm install --frozen-lockfile && pnpm build` |
| ما قبل النشر | `pnpm drizzle-kit migrate` لتطبيق الجداول والفهارس |
| التشغيل | `pnpm start`؛ الخادم يستعمل المنفذ الذي توفره المنصة عبر `PORT` |

يُثبِّت `render.yaml` إصدار Node متوافقاً مع التطوير. يدعم Render أيضاً تثبيت الإصدار من متغير `NODE_VERSION` أو ملف `.node-version`. [3]

## رفعه إلى GitHub

أنشئ مستودعاً فارغاً في حسابك ثم نفّذ الأوامر التالية من جذر المشروع بعد استبدال الرابط:

```bash
git init
git add .
git commit -m "Initial Solana signal scanner"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/solana-gem-scanner.git
git push -u origin main
```

لا ترفع ملف `.env` أو كلمات المرور أو رابط قاعدة بيانات يتضمن بيانات دخول. ستطلب منصة Render قيمة `DATABASE_URL` بصورة آمنة أثناء إعداد الـ Blueprint.

## البنية

```text
client/                 واجهة React + Tailwind ذات طابع HUD سيبراني
server/scanner/         مصدر DEX Screener، نموذج الدرجة، والأنواع
server/routers/scanner  واجهات tRPC العامة للفحص والإعدادات
server/scannerDb.ts     حفظ اللقطات والإعدادات واسترجاع آخر فحص
drizzle/                مخطط MySQL وترحيل الجداول
render.yaml             تعريف نشر Render
```

## القيود ومصدر البيانات

توفر وثائق DEX Screener ملفات التوكنات الأخيرة، وبيانات أزواج التوكنات، وحقول السيولة والحجم والمعاملات وتغير السعر وعمر الزوج؛ كما تنص على حدود طلبات للمسارات العامة. [1] لا تفترض اللوحة أن «الأحدث» يعني أفضل، ولا تعرض نتائج تجريبية حين لا يعيد المصدر مرشحين صالحين.
